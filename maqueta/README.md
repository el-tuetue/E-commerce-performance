# Maqueta

Archivos fuente de la maqueta hecha en el lienzo de diseño de Claude (formato `.dc.html`). No se abren directo en el navegador: son la referencia visual para construir las pantallas reales en Next.js.

| Archivo | Pantalla |
|---|---|
| `Portada.dc.html` | Portada de la propuesta |
| `Main.dc.html` | Tienda: inicio y catálogo |
| `Producto.dc.html` | Tienda: detalle de producto |
| `Carrito.dc.html` | Tienda: carrito y pago |
| `Login.dc.html` | Sistema interno: ingreso del personal |
| `Caja.dc.html` | Sistema interno: caja (vendedor) |
| `Admin.dc.html` | Sistema interno: administración (dueño) |
